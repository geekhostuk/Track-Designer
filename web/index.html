Export to Liftoff

Extract the zip over %USERPROFILE%\AppData\LocalLow\LuGus Studios\Liftoff\, then restart Liftoff. Exporting the same track again replaces this copy rather than adding another. Quit Steam before deleting Liftoff tracks — Steam Cloud silently restores them.

Export 3D model (.glb)

Exported at true scale — one metre in the designer is one metre in the file. Gate numbers and distance labels become flat panels facing the middle of the arena, because glTF has no billboard that turns to face you. Textures travel inside the .glb, so it is a single self-contained file.
